# PokéForge

**图形化宝可梦 ROM 修改器** · Electron + React + TypeScript · WinUI3 Fluent 浅色/暗色主题

覆盖 **第一世代（红 / 绿 / 蓝 / 皮卡丘）** 与 **第二世代（金 / 银 / 水晶，含汉化改版）** 的 GB/GBC ROM 图形化编辑。

## 功能总览

### 宝可梦
- **图鉴**：种族值 / 属性 / 捕获率 / 经验 / 初始招式 / 成长曲线（Gen1 五维特殊合并，Gen2 六维）
- **升级技能表**：升级招式 + 进化方式（等级/道具/通信/亲密度/攻防）+ 蛋组/孵化周期 + 特殊进化一览
- **招式机兼容**：Gen1 55 位 / Gen2 57 位 TM/HM 兼容位编辑 +「玩家想学就学」补丁（Gen2）
- **初始宝可梦**：御三家 / 波克比的蛋（Gen2）、脚本引用点统一改写（Gen1）、黄版皮卡丘亲密度

### 道具
- **道具属性**：价格 / 持有效果 / 口袋（Gen2）、BCD 价格表（Gen1）
- **商店货架**：Gen2 34 家商店、Gen1 script_mart 货架

### 世界
- **野生遭遇**：Gen2 91 张草丛表；Gen1 每图草丛+水面（57 张有遭遇的表）
- **传说遭遇**：Gen1 三圣鸟+超梦（地图物体）、Gen2 游走圣兽路线表
- **属性相克表**、**道馆人物**（Gen1 8 馆主+四天王、Gen2 17 道馆）、**人物队伍**（Gen2 66 类、Gen1 47 类）

### 工具
- **随机化器**（Gen2）、**存档编辑**（Gen2 队伍/DV/努力值/背包/徽章/盒子 + Gen1 黄版亲密度）
- **神兽直达**（写入存档坐标，两代各自适配）、**游戏中心**（Gen1 枯叶/玉虹奖品、Gen2 卡片翻牌奖品）
- **BUG 技巧库**：Gen2 8 条 + Gen1 68 条（按世代过滤），**金手指代码库**（按版本适配）
- **十六进制查看器**、**IPS 导出**、自动备份

## 技术要点
- 按世代隔离的 GameProfile 引擎：符号表交叉验证的数据表定位（不依赖硬编码偏移）
- 内置 GB LZ77 / GBK 图形解码、IPS 生成、Gen1/Gen2 存档校验和重算
- 汉化版 ROM（Tom_C 等）通过结构特征扫描兜底定位搬移后的数据表

## 使用
```bash
npm install
npm run build   # electron-vite 构建
npm start       # electron-vite preview 启动
```

打开 ROM 后所有编辑保存在内存，通过顶部「保存」写回（自动创建 .bak 备份），「导出 IPS」生成补丁。

> Gen3（GBA）尚未适配。仅供学习研究，请支持正版游戏。
